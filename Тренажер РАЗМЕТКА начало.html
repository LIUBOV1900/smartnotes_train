🎰 Тренажер «Испытай удачу» (PyQt5)

1. Создание виджетов — то, что видит пользователь

text  = QLabel('Победитель')          # надпись
text1 = QLabel('?')                   # надпись
text2 = QLabel('??')                  # надпись
button = QPushButton('Испытай удачу!') # кнопка

Виджет — объект в памяти. Пока он не попал в лейаут, а лейаут — в окно, на экране его нет (в тренажере такой объект подсвечен на «складе»).

2. Создание направляющей (лейаута)

line = QVBoxLayout()  # вертикальная — элементы в столбец ↕

Лейаут невидим: это «направляющая», расставляющая виджеты и растягивающая их при изменении размера окна. В этой программе лейаут один.

3. Виджет → в направляющую: addWidget + alignment

line.addWidget(text, alignment=Qt.AlignCenter)
line.addWidget(button, alignment=Qt.AlignCenter)

alignment — выравнивание виджета внутри ячейки лейаута: Qt.AlignCenter — по центру. Без него виджет растянулся бы на всю ширину.

4. Направляющая → в окно: setLayout

myWind.setLayout(line)

Делается один раз и «включает» разметку: всё дерево встает на свои места. Есть также setSpacing (промежутки) и setContentsMargins (поля), addStretch (пружина-распорка) — здесь не используются.

5. Обработка событий: connect

button.clicked.connect(show_winner)

Сигналу «клик по кнопке» привязывается функция show_winner: при клике в text1/text2 появятся случайные числа, при совпадении — «Вы победили», иначе — «Вы проиграли». Разметки это не касается, но без этого окно «мертвое».

6. Главное правило

Порядок операторов свободен: «сначала каркас, потом виджеты» и «заполняем по ходу» — равноценно. Важно только дерево вложенности (кто в ком лежит) и то, что переменная создана до использования. См. дерево под «складом» после сборки.

💡 До сборки — важное: есть два равноценных подхода. 1) «Сначала каркас»: собрать направляющие в дерево, потом разложить виджеты. 2) «Заполняем по ходу»: создаем направляющую и сразу кладем в нее виджеты. Для Qt порядок операторов не важен — важно лишь итоговое дерево вложенности. Когда сборка начнется, плашка исчезнет.
