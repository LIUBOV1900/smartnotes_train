🧩 Тренажер «Разметка окна» (PyQt5)

1. Создание виджетов — то, что видит пользователь

btn_OK = QPushButton('Ответить')               # кнопка
lb_Question = QLabel('деревня')                # надпись (текст)
RadioGroupBox = QGroupBox("Варианты ответов")  # рамка-группа с заголовком
rbtn_1 = QRadioButton('wilena')                # радиокнопка-переключатель

Виджет — это объект в памяти. Пока он не попал в лейаут, а лейаут — в окно, на экране его нет (в тренажере такой объект подсвечен на «складе»).

2. Создание направляющих (лейаутов)

layout_line1 = QHBoxLayout()  # горизонтальная — элементы в ряд ↔
layout_card  = QVBoxLayout()  # вертикальная — элементы в столбец ↕

Лейаут невидим: это «направляющая», которая расставляет виджеты и растягивает их при изменении размера окна.

3. Виджет → в направляющую: addWidget

layout_line2.addWidget(RadioGroupBox)
layout_line1.addWidget(lb_Question,
        alignment=(Qt.AlignHCenter | Qt.AlignVCenter))  # выравнивание
layout_line3.addWidget(btn_OK, stretch=2)               # доля «резинки»

alignment — как выровнять виджет внутри ячейки; stretch — с каким весом виджет тянет свободное место.

4. Направляющая → в направляющую: addLayout

layout_ans1.addLayout(layout_ans2)              # колонка — в ряд группы
layout_card.addLayout(layout_line1, stretch=2)  # строка — в главный лейаут

Так строится дерево вложенности: маленькие лейауты вкладываются в большие.

5. «Резинки» и промежутки: stretch и spacing

layout_line3.addStretch(1)  # пустая пружина — забирает свободное место
layout_card.setSpacing(5)   # промежуток между соседними элементами

stretch — вес распределения свободного места: stretch=2 тянет вдвое сильнее, чем 1. addStretch(1) ставит невидимую пружину-распорку (в тренажере — пунктир с подписью stretch(1)). setSpacing — расстояние между элементами лейаута; рядом существует setContentsMargins(л, в, п, н) — поля вокруг содержимого.

6. Главная направляющая → в окно / в группу: setLayout

RadioGroupBox.setLayout(layout_ans1)  # группе — свой лейаут
window.setLayout(layout_card)         # окну — главный лейаут

setLayout делается один раз и «включает» разметку: всё вложенное дерево встает на свои места.

7. Главное правило: два подхода равноценны

Подход 1 — «сначала каркас»: собрать дерево направляющих и затем разложить по ним виджеты. Подход 2 — «заполняем по ходу»: создавать направляющую и сразу класть в нее виджеты. Для Qt порядок операторов свободен — важно только дерево вложенности (кто в ком лежит) и то, что переменная создана до использования. См. дерево под «складом» после сборки.

💡 До сборки — важное: есть два равноценных подхода. 1) «Сначала каркас»: собрать направляющие (лейауты) в дерево, а потом разложить по ним виджеты. 2) «Заполняем по ходу»: создаем направляющую и сразу кладем в нее виджеты. Для Qt порядок операторов не важен — важно лишь итоговое дерево вложенности. Когда сборка начнется, плашка исчезнет.
